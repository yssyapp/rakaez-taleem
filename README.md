# منصة ركائز التعليم (Rakaez Taleem)

تطبيق تعليمي متكامل مبني بتقنية **Flutter** لإدارة العملية التعليمية، مع قاعدة بيانات وخدمات **Firebase**.

## المزايا الرئيسية

- تسجيل دخول آمن للمستخدمين
- لوحة تحكم تعرض إحصائيات سريعة (عدد الطلاب، عدد المعلمين، الزيارات، نسبة الحضور)
- إدارة الطلاب
- إدارة المعلمين
- متابعة الزيارات والمواعيد
- عرض التقارير

## التقنيات المستخدمة

- **Flutter** — إطار العمل الأساسي لبناء التطبيق
- **Firebase** — المصادقة وقاعدة البيانات
- **Riverpod** — إدارة الحالة (State Management)

## بدء التشغيل محليًا

```bash
flutter pub get
flutter run
```

> ملاحظة: يتطلب التطبيق ملف `lib/firebase_options.dart` الخاص بإعدادات Firebase، وهو مستثنى من المستودع لأسباب أمنية (راجع `.gitignore`).
